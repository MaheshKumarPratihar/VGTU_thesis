' Processes
rectangle "1.0\nData Validation\n& Preprocessing" as P1
rectangle "2.0\nGAI Data\nAugmentation" as P2
rectangle "3.0\nEmbedding\nGeneration" as P3
rectangle "3.1\nBERT\nEncoding" as P3A

' Data Stores
database "D1: Raw Text\nCorpus" as D1
database "D2: Preprocessed\nText Data" as D2
database "D3: Embedding\nVectors" as D3
database "D4: SOM Models\n& Configurations" as D4
database "D5: Clustering\nResults" as D5
database "D6: Evaluation\nMetrics" as D6
database "D7: Cluster\nMetadata" as D7

' Main Data Flows
User --> D1 : Upload raw\ntext dataset
D1 --> P1 : Raw documents
P1 --> D2 : Cleaned & tokenized\ntext data
P1 ..> User : Validation errors\n(if any)

D2 --> GAI : Dataset statistics\n& distribution
GAI --> P2 : Augmentation request
P2 --> D2 : Synthetic samples\n(balanced dataset)
D2 --> P3 : Preprocessed texts

' Embedding Generation (Parallel)
P3 --> P3A : Texts for BERT
P3 --> P3B : Texts for BoW
P3 --> P3C : Texts for Word2Vec

P3A --> D3 : BERT embeddings\n[n × 768]
P3B --> D3 : BoW vectors\n[n × vocab_size]
P3C --> D3 : Word2Vec embeddings\n[n × 300]

' GAI Hyperparameter Optimization
D3 --> GAI : Embedding statistics\n(dimensions, density)
GAI --> P4 : Parameter suggestions
P4 --> D4 : Hyperparameter grid\n(grid_size, learning_rate,\nsigma, iterations)

' SOM Training Loop
D3 --> P5 : Normalized embeddings
D4 --> P5 : SOM configurations
P5 --> D5 : Cluster assignments\n& trained models
P5 --> D4 : Updated model weights

' Evaluation
D5 --> P6 : Clustering results
P6 --> D6 : Quality metrics\n(Silhouette, Davies-Bouldin,\nCalinski-Harabasz)

' GAI Cluster Interpretation
D5 --> GAI : Cluster documents
GAI --> P7 : Interpretation request
P7 --> D7 : Cluster labels\n& summaries

' Visualization & Results
D5 --> P8 : Cluster data
D6 --> P8 : Metric scores
D7 --> P8 : Cluster descriptions
P8 --> User : Visualizations\n(SOM heatmap, t-SNE,\nsilhouette plots)

' Feedback Loops
P6 ..> P4 : Poor metrics\n(adjust parameters)
P6 ..> P5 : Re-train request
P7 ..> GAI : Clarification needed
D6 ..> User : Metric comparison\nreport

' Cross-references
D3 -.> P6 : Original embeddings\n(for metric calculation)
D2 -.> P7 : Original texts\n(for interpretation)

note right of P2
  GAI Data Augmentation:
  - Analyzes class distribution
  - Generates synthetic samples
  - Maintains semantic coherence
  - Balances dataset
end note

note right of P3
  Three Parallel Pipelines:
  • BERT: Contextual embeddings
  • BoW: Traditional frequency
  • Word2Vec: Static word vectors
end note

note right of P4
  GAI Optimization:
  - Analyzes embedding properties
  - Suggests grid sizes
  - Recommends learning rates
  - Optimizes neighborhood params
end note

note right of P5
  SOM Training Process:
  1. Initialize topology
  2. Find Best Matching Units
  3. Update neuron weights
  4. Decay learning parameters
  5. Assign final clusters
end note

note right of P6
  Evaluation Metrics:
  • Silhouette: [-1, 1] ↑
  • Davies-Bouldin: [0, ∞) ↓
  • Calinski-Harabasz: [0, ∞) ↑
  • Within-cluster variance ↓
  • Between-cluster distance ↑
end note

note right of P7
  GAI Interpretation:
  - Generates semantic labels
  - Creates cluster summaries
  - Extracts key themes
  - Identifies distinguishing features
end note

note bottom of D5
  PRIMARY OUTPUTS:
  • Optimal cluster assignments
  • Best embedding method
  • Optimal hyperparameters
  • Quality metrics comparison
  • GAI-generated insights
end note
